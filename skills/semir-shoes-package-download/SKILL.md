# 森马云盘鞋品图包下载 Skill

## 概述

本 Skill 用于从森马云盘批量下载鞋品图包图片，支持按款号在「品牌视觉部 / 服饰包装组 / 巴拉服饰产品包装 / 01-产品包装」目录下查找并下载 1440_1440 尺寸的图片。

## 云盘信息

| 项目 | 值 |
|------|---|
| 挂载点 ID | `1863`（巴拉巴拉品牌事业部-市场系统） |
| 云盘根路径 | `品牌视觉部/服饰包装组/巴拉服饰产品包装/01-产品包装` |
| 子目录结构 | `2026Q3/鞋品/<款号>/{主图, 颜色, 创意拍}` |

## 核心逻辑

### 搜索策略

**关键原则**：遍历季度目录 → 定位款号文件夹 → 遍历子文件夹

1. **遍历季度目录**：按 `2026Q3 → 2026Q2 → 2026Q1 → 2025Q4...` 顺序遍历
2. **定位款号目录**：在每个季度的 `鞋品` 目录下查找款号对应的文件夹
3. **识别子文件夹**：识别 `主图`、`颜色`、`创意拍` 三种文件夹
4. **筛选图片**：下载文件名包含 `1440_1440` 的图片
5. **数量控制**：每个款号最多 10 张图片（主图+颜色 不够时补充创意拍）

### 目录识别规则

款号文件夹下存在以下三种子文件夹：

| 文件夹名 | 作用 | 优先级 |
|---------|------|--------|
| `主图` | 商品主图 | 第一优先 |
| `颜色` | 颜色图 | 第二优先 |
| `创意拍` | 创意拍摄图 | 补充下载（不足 10 张时） |

### 图片下载逻辑

1. **优先下载主图+颜色文件夹**中的 1440_1440 图片
2. **如果不足 10 张**，继续从创意拍文件夹补充
3. **跳过已下载的文件**（避免重复下载）
4. **累计最多 10 张**

## 图片匹配规则

下载文件名包含 `1440_1440` 的图片，支持以下格式：

- `1440_1440.jpg`
- `1440_1440(天猫).jpg`
- `1440_1440(天猫)1.jpg`
- `1440_14401.jpg`（无下划线分隔）

**文件后缀**：`jpg`、`jpeg`、`png`

按以下顺序遍历季度目录（最新优先）：

```
2026Q3 → 2026Q2 → 2026Q1 → 2025Q4 → 2025Q3 → 2025Q2 → 2025Q1
```

## 常见问题

### Q: 找不到款号目录？

**可能原因**：
1. 款号不在鞋品目录下，可能在「巴拉货控」等其他挂载点
2. 款号尚未上架
3. 款号路径可能在其他年份

**解决方法**：
- 确认款号是否存在
- 扩大搜索范围到其他挂载点（mount 2023）
- 检查季度目录

### Q: 创意拍文件夹没有图片？

**正常情况**：不是所有款号都有创意拍文件夹，属于正常情况

### Q: 下载数量不足 10 张？

**可能原因**：
1. 该款号本身只有少量 1440_1440 图片
2. 该款号没有创意拍文件夹

**解决方法**：
- 确认是否有其他尺寸图片
- 检查款号是否完整

### Q: 文件名重复？

**可能原因**：主图和颜色文件夹中存在相同文件名的图片

**解决方法**：
- 脚本会自动跳过已下载文件
- 重复文件会被去重（同名同尺寸）
