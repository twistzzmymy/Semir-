# 错误学习库（Error Knowledge Base）

本库用于记录千牛/天猫商品发布流程中遇到的错误与已验证的解决方案。
格式：每条记录含错误签名（匹配关键词）、现象、根因、解决方案、验证信号。
主流程脚本在提交报错后自动查询本库；命中则按解决方案执行，未命中则追加"未知错误"记录等待人工补充方案。

## 同类宝贝|达到[5]个|不允许再发布
- id: ERR-001
- 现象: 提交时全局报错"您已发布过同类宝贝达到[5]个，不允许再发布"，操作码形如 213e050d.../213e0484...
- 根因: 账号在该类目下已发布同款商品达到 5 个上限，判定维度为"账号+类目+同款"，改货号可规避
- 验证: 提交后无"同类宝贝"报错；页面无全局错误条
- 状态: verified
- 首次发现: 2026-09-22
- 次数: 2
- 解决方案:
  1. 打开"切换类目"弹窗（编辑页"当前类目"右侧"切换类目"按钮）
  2. 品牌输入框注入"巴拉巴拉"（React setter + input/change 事件）
  3. 点击下拉中的"巴拉巴拉"选项（必须点中选项本体，否则"确定"按钮保持 disabled）
  4. 货号输入框注入"<基础货号>-N"（N 从 1 开始递增，如 208426107207-2）
  5. 点击"确定"（确认按钮 disabled=false 后方可点击）→ 弹窗关闭、页面刷新
  6. 验证：页面刷新回图文描述、全局报错消失、基础信息"*货号"字段显示为 <基础货号>-N
  7. 从"图文描述"重新执行完整流程后再提交

## 旺铺PC详情|旺铺详情编辑器|请编辑电脑端详情
- id: ERR-002
- 现象: 提交时校验拦截，提示旺铺PC详情必填/需要编辑电脑端详情；426批次 row272（200426133201）亦命中
- 根因: 发布相似品默认落在旺铺编辑器模式，克隆的旧描述在文本编辑器里，旺铺编辑器内容为空
- 验证: 提交时不再报"旺铺PC详情必填"
- 状态: verified
- 首次发现: 2026-09-22
- 次数: 4
- 解决方案:
  1. 点击"图文描述"tab（顶部 tab 栏，位置随商品/类目变化，全视口定位）
  2. 主路径A：找"编辑电脑端详情"按钮（旺铺PC详情模块 y≈838）→ 滚动可见 → 点击打开编辑器（部分商品有效）
  3. 主路径B（通用，2026-09-29 row60 实测）："返回旧版图文描述"按钮可能在**页面横向滚动区 x≈1487 超视口 + 纵向视口外 y≈2856**——必须 `scrollIntoView({block:'center', inline:'center'})` 横纵双滚动后再 CDP 点击（只纵向滚动点击落空）
  4. 弹窗"确认返回旧版吗"→ 点"确定"（兜底任何"确定/确认"）
  5. 返回旧版后"使用文本编辑" LABEL 渲染（x≈463,y≈766,98x18）——**该 radio 是隐藏组件，点击 leaf 文本/JS click()/change/React setter 均不选中，必须 CDP 点击 LABEL 祖先**（label>radio-item>sell-radio 链），点击后重查 checked 最多3轮
  6. 验证：`使用文本编辑` radio checked=True + ks-editor iframe 图片数>0（36/44 张）
  7. 若展开后仍无"使用文本编辑"（特殊类目如发育内衣/抹胸），标记人工处理（PC详情在跨域 iframe 装修编辑器内）

## 必填项缺失|不能为空|必填项缺失:面料
- id: ERR-004
- 现象: 提交被拦截：必填项适用人群不能为空 / 必填项绒子含量不能为空 / 必填项缺失:面料（羽绒/特殊类目克隆后必填属性为空）
- 根因: 克隆相似品未携带该类目必填属性（适用人群/绒子含量等）
- 验证: 重新提交通过
- 状态: verified
- 首次发现: 2026-09-24
- 次数: 4
- 解决方案:
  1. 适用人群（next-select 单选）：错误行"必填项适用人群不能为空"同列定位（x差<60）→ elementFromPoint 向上找 .next-select → JS dispatchEvent mousedown+mouseup+click 展开（CDP click 无效）→ 选项容器 scrollTop=0 强制渲染顶部 → 候选（儿童/女童/男童）scrollIntoView 点击
  2. 绒子含量（input 数字）：CDP 点击聚焦 input（按"绒子含量"标签行 x±420/y±70 定位）→ Ctrl+A → type_text('90') → Tab（React setter+input/change 不被 React 接收，勿用）
  3. resubmit 循环 range(4)：连续暴露多个必填项时留足轮次
  4. 面料/里料/填充物等多选组件：**不做自动选择**（用户明确指令 2026-09-24：只负责ID克隆，遇到错误记录跳过该款），错误记录后跳过

## 旧描述|淘金币|tps-1240-450|促销图
- id: ERR-006
- 现象: 克隆商品的"旧描述(选填)"模块带平台淘金币促销banner（原图 1240x450，"点击享大额补贴/立即购买/优惠仅限手机端淘宝APP有效"，src 含 tps-1240-450.png，为编辑器内 img[0]）
- 根因: 发布相似品克隆时，旧描述模块复制了平台插入的淘金币促销图；用户要求删除
- 验证: 旧描述编辑器内该图消失（39→38）、img[0] 变为占位图；提交描述不含促销图
- 状态: verified
- 首次发现: 2026-09-29
- 次数: 1
- 解决方案:
  1. 点击"图文描述"tab（顶部 tab 栏，全视口定位）
  2. 下滑到"旧描述(选填)"模块（正文文本"旧描述"所在行）
  3. 点击该行右侧的"编辑/展开"按钮（同 y±40、x 差 >300 范围内的"编辑"，勿点上方其他模块的编辑）
  4. 等待编辑器打开（可见 ks-editor-iframe 出现）
  5. 扫描可见编辑器内全部 img，命中 src 含 'tps'+'1240-450' 或 '6000000007501' 或 'vWMf4v25HV'（或 natural 1240x450）的图均为淘金币图——**克隆会带多张变体（HVynQwwXa_/HVymQwwXa_ 等 CDN 变体），只删首图不够，须全量删除**
  6. img.remove() + 编辑器 body dispatch input/change 事件（同步富文本编辑器）
  7. **iframe 直删兜底（2026-09-29 row60 实证）**：主文档找不到"旧描述编辑"按钮时，旧描述图在 ks-editor-iframe 内——直接扫所有编辑器 iframe 全量删特征图，不依赖按钮
  8. 验证 remaining_promo=0；无特征图时返回 found=False（无需清理，正常）
